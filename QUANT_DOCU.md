
## Documentation for SatNerf Quantization

### Files

- All files inside `quantization/` directory
- `export_new.sh` and its accompanying python file, `main-export.py`
- `rendering_trt.py` 
- `trt_infer_new.sh` 
- `requirements-quant.txt`
- `requirements.txt`

### Reproducing environment.

- Important packages are listed inside the requirements.txt files and inside the `setup_*_env.sh` scripts
- If installation has unmet dependencies, here is a list of important packages:
  1. TensorRT, 
  2. polygraphy,
  3. Pytorch, 
  4. onnx and onnxruntime

### How to run the quantization

1. Train a new model using the `train_new.sh` scripts, configurations available inside the script file is as follows:
   - batch and chunk (will affect the memory usage)
   - how many layers, units and samples for the models
   - which scene to train for, and where to store the locations of the resulting json and model checkpoints
   - How many epochs to go before saving a checkpoint to disk

2. Export the models to ONNX, FP16 and Int8 format with `bash export_new.sh` 
   - Note: in this code, it will check inside the folders available in `/data/satnerf/exp`, given inside `train_new.sh`, change to new location as desired
   - By default this script will try to save to `/data/satnerf/generated/models/[MODELS]`, change to new location as desired

### How to check the performance of the quantized model

1. Edit the `eval_satnerf_trt.py` to the correct details, pointing the following variables to the correct paths:
   - `run_id`: where the results from training is stored,
   - `logs_dir`: inside the `run_dir`, there is a child folder called `logs/[TIMESTAMP]` to accomodate for multiple runs, point to the run you want to check
   - `epoch_number`: model checkpoint to check, check inside the `checkpoints/[TIMESTAMPS]` directory inside `run_dir` for available checkpoints, value given here is `checkpoint_value-1`
   - `checkpoint_path` (line 102 inside the .py file): this is a hardcoded path to the checkpoint, containing the [TIMESTAMPS] value in `checkpoints/[TIMESTAMPS]`, change accordingly
   - `models["trt"]` (line 124 inside the .py file): a hardcoded path to the TensorRT file to check (generated by the `export_new.sh` script, adjust accordingly)
